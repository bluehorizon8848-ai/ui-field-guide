# 首发选题

10 篇，写完即可发。每篇都是独立内容，不依赖前文。

**格式约定**：标题带「# 」，正文分隔线以下是正文，`---` 之后是发布备注。
发布到不同平台时删掉最顶部的 `# ` 标题行和「## 痛点」这类小标题即可。

## 改写建议

每篇发到不同平台时：

**小红书**（500-1000 字）
- 删掉所有二级小标题
- 决策表改成有序列表
- 结尾不要放网址，用「评论区问你要链接」或直接放主页

**掘金 / 少数派**（保留结构）
- 保留小标题和表格
- 开头加一段「背景」
- 链接用完整 URL

**即刻**（200 字以内）
- 只留「痛点 + 一句话结论 + 一张图」
- 每篇的核心结论单独成帖

**朋友圈 / X**
- 只取每篇最后那行「一句话记住」
- 配分享卡片图

## 每篇的固定结构

```
标题（带痛点或反差）
↓
## 痛点      —— 真实场景，不讲理论
↓ 关键洞察    —— 一条可迁移的判断规则
↓ 怎么用      —— 决策表 / 步骤
↓ 怎么告诉 AI —— 完整 Prompt 示例
↓ 延伸        —— 相关词条链接
↓
一句话记住
```

**「怎么告诉 AI」这一段不要删。** 它是这个产品存在的理由，也是和其他 UI 教程最明显的区别。

## 配图建议

每个词条都有分享卡片（3:4 和 1:1），可以直接当配图。

生成方式：打开对应词条页 → 页面底部「分享卡片」→ 选比例 → 下载 PNG。

已生成的卡片：
- 小红书 / Instagram → 1:1
- 公众号 / 知乎 → 3:4

Demo 截图建议用浏览器整页截图，突出「能交互」这一点 —— 静态图看不出可交互是产品的核心优势。
